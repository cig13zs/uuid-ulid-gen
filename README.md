# Uuid-ulid-gen

Generate cryptographically secure UUID v4/v7, ULIDs, and NanoIDs in bulk offline.

## What it does

Runs 100% offline in your browser. Zero tracking, zero network requests.

## Install

1. Download latest zip from [Releases](https://github.com/cig13zs/uuid-ulid-gen/releases).
2. Open chrome://extensions and turn on **Developer mode**.
3. Click **Load unpacked** and select extension.
